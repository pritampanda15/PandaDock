## 🔍 How to Run a Test Docking Job

Here’s how to quickly test PandaDock after installing it:

### 🧪 Example Files
Make sure you have:
- `protein.pdb` – a protein structure
- `ligand.sdf` – a ligand molecule

### 🚀 Run This Command

```bash
pandadock -p protein.pdb -l ligand.sdf --grid-radius 10

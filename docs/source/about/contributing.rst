Contributing
============

Contributions to **PandaDock** are welcome!

1. Fork the repository at https://github.com/pritampanda15/PandaDock.
2. Create a feature branch and install in editable mode: ``pip install -e ".[gui,gnn]"``.
3. Run the test suite (``pytest tests/``) and syntax/lint checks (``flake8``) before submitting a Pull Request.
4. Report bugs or request features via GitHub Issues: https://github.com/pritampanda15/PandaDock/issues.

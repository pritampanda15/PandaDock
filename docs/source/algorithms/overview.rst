Algorithms Overview
===================

PandaDock provides 10+ advanced docking algorithms optimized for different use cases.

Algorithm Categories
--------------------

**CPU Algorithms** (5 variants)

* Enhanced Hierarchical CPU
* Monte Carlo CPU
* Genetic Algorithm CPU
* Hierarchical CPU
* Crystal Guided CPU

**GPU Algorithms** (3 variants)

* Enhanced Hierarchical GPU
* CUDA Monte Carlo
* CUDA Genetic Algorithm

**Specialized Modes**

* Flexible Docking (pandadock-flex)
* Metal Docking (pandadock-metal)
* ML Docking (pandadock-ml)
* Tethered Docking (pandadock-tethered)

For detailed documentation, see the subsections.

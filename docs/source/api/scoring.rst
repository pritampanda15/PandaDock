Scoring Python API
==================

Empirical, physics-based, MM-GBSA, and calibrated scoring modules:

* ``pandadock.docking.scoring.vina`` — AutoDock Vina & Vinardo grid-accelerated scoring
* ``pandadock.docking.scoring.physics_based`` — Explicit electrostatics, VdW, H-bond & desolvation
* ``pandadock.docking.scoring.mmgbsa`` — Fast vectorized differential 12 Å pocket MM-GBSA rescorer
* ``pandadock.docking.scoring.waters`` — Displaceable & bridging crystallographic water scoring
* ``pandadock.calibration`` — Per-target few-shot Ridge LOOCV weight calibration

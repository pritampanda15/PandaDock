Analysis, Visualization & Studio GUI API
========================================

Reporting, 300-DPI diagnostics, PandaMap diagrams, and PandaDock Studio backend:

* ``pandadock.visualization.report_kit`` — Panda-family A4 vector brochure layout kit
* ``pandadock.visualization.report_pdf`` — Multi-page publication ``report.pdf`` builder
* ``pandadock.visualization.report`` — Editorial ``report.html`` generator
* ``pandadock.visualization.report_plots`` — 300-DPI scoring funnel, MDS landscape, RMSF & hotspot plots
* ``pandadock.gui.server`` — FastAPI + SSE backend for **PandaDock Studio** (``pandadock-gui``)
